AIScan Framework v1.0.0-PRO — NOTAS DA BETA
============================================

1. A IDEIA
---------
Ferramenta focada em falhas de sites gerados por IA (Lovable.dev, v0.dev,
Bolt.new). A febre desses builders entrega codigo rapido com seguranca zero:
quem nao programa publica sem RLS, sem headers, com secrets no bundle.
Bug bounty de IA e first-mover: quem chega primeiro bebe agua limpa.

-------------------

  comandos: set target | set mode <manual/pro> | show options |
            show modules | run | run module <nome.lua> | exit
  run = recon -> exploit Supabase -> todos os modulos Lua -> relatorio IA (PRO)
  PRO com timeout 90s + retry com backoff + aviso de espera no console

  lower() Unicode-correto, sanitize anti-quebra UTF-8
