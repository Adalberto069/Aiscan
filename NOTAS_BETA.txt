2. O QUE FOI CRIADO
-------------------
aiscan.py ............ console interativo estilo msfconsole
  comandos: set target | set mode <manual/pro> | show options |
            show modules | run | run module <nome.lua> | exit
  run = recon -> exploit Supabase -> todos os modulos Lua -> relatorio IA (PRO)
  PRO com timeout 90s + retry com backoff + aviso de espera no console

core/scanner.py ...... AIParser: fingerprint de build IA
  (Lovable/Bolt, Vite main.tsx/bundle hash, Shadcn/Radix, Tailwind,
   Supabase, Firebase) com calibragem anti-falso-positivo

core/exploits.py ..... testa Supabase REST exposto (/rest/v1/ -> 200 = sem RLS)

core/lua_engine.py ... runtime Lua via lupa p/ modulos da comunidade
  API exposta: http_get, http_status, http_headers, find_regex (regex Python),
  lower() Unicode-correto, sanitize anti-quebra UTF-8

core/ai_engine.py .... agente PRO_MAX (Gemini 3.5-flash, fallback p/ flash-latest
  e 3.8-flash), prompt de auditoria defensiva, retry contra 504

modules/ai_signatures.lua .. fingerprint 9 sinais + veredito ALTA/MEDIA/BAIXA
modules/supabase_enum.lua .. acha base + testa /rest/v1/ + fuzza 10 tabelas
modules/headers_audit.lua .. 6 headers que IA nunca configura
